Troubleshooting Guide

Why Isn't My Link Generated?

Follow these quick steps to get your GitHub Pages site deployed and live.

Step 1

Save Branch Selection

Under Build and deployment, set your source branch to main and folder to /(root). Click Save.

Step 2

Trigger Initial Deployment

Ensure your main branch contains an index.html or README.md file so GitHub can start the build process.

Step 3

Check Workflow Status

Go to the Actions tab in your repository to confirm that pages-build-deployment has finished running.

🚀

Ready to verify?

Refresh your Pages settings after a minute to view your new URL:

https://your-username.github.io/your-repo/
